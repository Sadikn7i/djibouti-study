# Structural Transformation in Djibouti – Geospatial Analysis

This project assesses the **structural transformation** of Djibouti using data from the world Bank It applies **three different analytical models** to understand industrial change and service transformation.

## Project Goals


- Compare results across three transformation models
- Utilize open several robust model analysis

## Structure

- `notebooks/`: Contains the Jupyter Notebook (`DjibIgad.ipynb`) with all the model workflows
- `scripts/`: Placeholder for Python scripts (if needed later)
- `data/`: Directory for raw or processed input data
- `outputs/`: Visualizations, maps, or model results

## Requirements

This project uses the following tools:

- `geopandas`
- `rasterio`
- `earthengine-api`
- `matplotlib`
- `folium`
- `xarray`, `rioxarray`

Use a virtual environment and install dependencies using `pip` or `conda`.
